## 1단계: 멀티 인스턴스 / 멀티 윈도우 (창 여러 개)

### 개요
사용자가 요청한 "창을 여러 개 띄워서 여러 파일을 볼 수 있게" 하는 기능.

### 구현 방식
- `--new-window` 커맨드라인 플래그로 새 인스턴스 실행
- 우클릭 → "새 창에서 열기"
- 드래그앤드롭으로 새 창 생성
- 창 간 동기화 재생 옵션 (같은 타임코드로 동기화)

### 차별점
팟플레이어도 멀티 인스턴스를 지원하지만, **창 간 동기화 재생**은 없음. 영화 비교 분석, 듀얼 모니터 활용에 독보적.

## 2단계: 스마트폰 연동 (핸드폰과 함께)

### 2-1. 스마트폰 리모컨
- 같은 Wi-Fi에서 스마트폰 브라우저로 `http://[PC-IP]:8765` 접속
- 재생/일시정지, 볼륨, 시크, 자막 선택을 스마트폰에서 제어
- QR코드로 즉시 연결 (설정 불필요)
- **차별점**: 팟플레이어는 없음. VLC에 있지만 UI가 구림.

### 2-2. 스마트폰 → PC 파일 전송
- 스마트폰에서 촬영한 영상을 Wi-Fi로 직접 PC 소리누리에 전송 → 즉시 재생
- 드래그앤드롭 없이 "소리누리로 보내기" 버튼 하나로 완성

### 2-3. PC → TV 캐스팅 (크롬캐스트/AirPlay 완성)
- 현재 재생 중인 영상을 스마트 TV로 1클릭 캐스팅
- 소리누리가 로컬 HTTP 서버 역할 → 크롬캐스트가 스트리밍

## 3단계: 케이블/IPTV PC 시청

### 개요
"케이블 방송을 PC에서 볼 수 있게" — IPTV/케이블 방송사의 m3u8 스트림을 소리누리에서 직접 재생.

### 구현 방식
- KT/SK/LG IPTV의 공개 EPG + m3u8 채널 목록 자동 수집
- 채널 그리드 UI (TV 채널 번호 + 로고 + 현재 방영 프로그램)
- 예약 녹화 기능 (ffmpeg 백엔드)
- **차별점**: 팟플레이어/VLC에서 m3u8을 수동으로 입력해야 하는 것을 채널 UI로 완성

## 4단계: AI 기반 스마트 기능 (소리누리만의 독보적 기능)

### 4-1. AI 장면 검색
- "키스 장면 찾아줘", "액션 장면만 보여줘" → AI가 영상을 분석해서 해당 장면으로 이동
- Whisper 음성 인식 + 장면 분류 모델 활용
- **차별점**: 세상 어떤 플레이어에도 없는 기능

### 4-2. AI 자동 하이라이트
- 영화/스포츠 영상에서 하이라이트 장면 자동 추출
- 음량 급상승, 빠른 컷 전환, 음성 감정 분석으로 하이라이트 감지
- **차별점**: 세상 어떤 플레이어에도 없는 기능

### 4-3. AI 번역 자막 실시간 생성
- 외국어 영상에서 Whisper로 음성 인식 → DeepL로 실시간 번역 → 자막 오버레이
- 인터넷 연결 없이도 로컬 모델로 동작 가능
- **차별점**: 현재 소리누리에 Whisper 자막이 있지만 번역까지 실시간으로 하는 플레이어는 없음

### 4-4. 얼굴 인식 자막 화자 표시
- 영상에서 말하는 사람의 얼굴을 인식 → 자막에 화자 이름 표시
- "홍길동: 안녕하세요" 형태로 자막 표시
- **차별점**: 세상 어떤 플레이어에도 없는 기능

## 5단계: 소셜/공유 기능

### 5-1. 타임스탬프 공유
- 영상의 특정 장면을 "소리누리 링크"로 공유
- 링크 클릭 시 소리누리가 해당 파일의 해당 시점부터 재생
- **차별점**: 유튜브의 `?t=` 파라미터를 로컬 파일에 적용

### 5-2. 영상 클립 추출 + 공유
- 현재 재생 중인 영상에서 A-B 구간을 GIF/MP4 클립으로 즉시 추출
- 카카오톡, 디스코드 등으로 바로 공유
- **차별점**: 팟플레이어에 클립 추출 있지만 공유 연동 없음

---

## 6단계: 하이엔드 오디오 전용 기능

### 6-1. 바이노럴 렌더링
- 5.1/7.1 채널 영상을 헤드폰으로 들을 때 입체감 있게 변환
- HRTF(Head-Related Transfer Function) 적용
- **차별점**: JRiver에만 있는 기능을 무료로 제공

### 6-2. 오디오 스펙트럼 분석기
- 재생 중인 오디오의 실시간 주파수 스펙트럼 표시
- 비트퍼펙트 여부, 클리핑 감지, 다이나믹 레인지 표시
- **차별점**: 오디오파일 사용자에게 필수 기능
