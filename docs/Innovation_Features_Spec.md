# 소리누리 혁신 기능 상세 기획안 (v4.0)

## 1. AI 실시간 자막 생성 (Whisper AI)

### 개요
외국어 영상 시청 시, 자막 파일이 없어도 실시간으로 음성을 인식하여 한국어 자막을 생성하고 표시하는 기능입니다.

### 기술 스택
- **엔진**: `faster-whisper` (Python)
- **통신**: Qt 앱 ↔ Python 스크립트 간 QProcess 통신 (stdin/stdout)
- **모델**: `medium` (기본), `base` (저사양용), `large-v3` (고사양용)
- **하드웨어 가속**: NVIDIA CUDA, AMD ROCm 지원

### UI/UX 상세
- **진입점**: `ControlBar`에 `[AI 자막]` 토글 버튼 추가
- **설정 패널**: `ProFeaturesWidget`의 새 탭으로 구성
  - **인식 언어**: 자동(기본) / 영어 / 일본어 / 중국어 등
  - **번역**: 한국어로 번역 (토글 스위치)
  - **모델 선택**: base / medium / large
  - **상태 표시**: GPU 가속 활성화 여부, 현재 인식 중인 문장 미리보기

### 동작 흐름
1. 사용자가 AI 자막 기능 활성화
2. `MpvCore`에서 오디오 스트림을 추출하여 임시 파이프로 전달
3. `faster-whisper` 프로세스가 오디오를 분석하여 텍스트 생성
4. `SubtitleManager`를 통해 화면에 자막 표시

## 2. AI 화질 업스케일링 (RTX VSR / FSR)

### 개요
1080p 이하의 저화질 영상을 4K 해상도로 실시간 업스케일링하여 선명하게 보여주는 기능입니다.

### 기술 스택
- **엔진**: MPV 내장 `gpu-next` 비디오 출력 모듈
- **NVIDIA**: RTX VSR (Video Super Resolution) 지원 (`hwdec=d3d11va`, `scale=ewa_lanczossharp` 등 조합)
- **소프트웨어**: MPV 내장 고품질 스케일러 (Lanczos, Spline36)

### UI/UX 상세
- **진입점**: `ControlBar`에 `[화질 개선]` 버튼 추가
- **설정 패널**: `ProFeaturesWidget`의 새 탭으로 구성
  - **업스케일 모드**: OFF / NVIDIA RTX VSR / AMD FSR / 소프트웨어(Lanczos)
  - **강도 슬라이더**: 1 ~ 4 단계 조절
  - **비교 모드**: 화면을 반으로 나누어 좌측 원본, 우측 업스케일 화면 비교 (목업 참조)

### 동작 흐름
1. GPU 제조사 자동 감지 (NVIDIA/AMD)
2. 호환되는 하드웨어 가속 방식 자동 추천
3. MPV 프로퍼티(`vo`, `scale`, `glsl-shaders`) 실시간 변경 적용

## 3. 스마트 챕터 & 북마크

### 개요
영상의 장면 전환을 감지하여 자동으로 챕터를 나누고, 사용자가 북마크를 추가할 수 있는 기능입니다.

### 기술 스택
- **장면 감지**: MPV의 `--scene-detection` 필터 활용 또는 Python `scenedetect` 라이브러리
- **타임라인**: `ControlBar`의 시크바 확장 (마커 표시, 썸네일 팝업)

### UI/UX 상세
- **타임라인 마커**: 시크바 위에 작은 세로선으로 챕터/북마크 위치 표시
- **썸네일 팝업**: 시크바에 마우스를 올리면 해당 시간의 썸네일과 챕터 제목 표시
- **단축키**: `B` (북마크 추가), `[`, `]` (이전/다음 챕터 이동)

## 4. 멀티뷰 & PIP (Picture in Picture)

### 개요
하나의 영상 위에 다른 영상을 작게 띄우거나, 여러 영상을 분할 화면으로 동시 재생하는 기능입니다.

### 기술 스택
- **구현**: 여러 개의 `MpvWidget` 인스턴스를 생성하고 레이아웃으로 관리
- **오디오**: 메인 영상의 오디오만 출력, 서브 영상은 음소거 처리

### UI/UX 상세
- **레이아웃 옵션**: PIP (우측 하단 작은 창), 듀얼 (좌우 분할), 쿼드 (2x2 분할)
- **컨트롤**: 각 창마다 독립적인 재생 제어 미니 오버레이 제공
- **드래그 앤 드롭**: 외부에서 영상 파일을 드래그하여 특정 분할 영역에 드롭 시 해당 영역에서 재생
