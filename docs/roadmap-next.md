# 소리누리 다음 버전 개선 로드맵

현재 버전: **v4.3.10** (2026-07-31)

## 이번 버전(v4.3.10)까지 완료된 사항

| 구분 | 내용 |
| --- | --- |
| 핵심 버그 | 파일 열기 시 자동 재생 안 되던 문제 근본 해결 (패스스루 미지원 장치에서 오디오 초기화 실패 → 자동 복구 + 2초 워치독) |
| 개인정보 | 진단 로그 파일 기록 기본 비활성화 (사용자 PC에 로그 파일 미생성) |
| 인프라 | GitHub Actions → sorinuri.com 자동 빌드/배포, 자동 업데이트 팝업 |

## 다음 버전 개선 예정 기능

### 1순위: 안정성/품질 마무리 (v4.4.x)

| 기능 | 설명 | 상태 |
| --- | --- | --- |
| 렌더링 안정화 | 로그에서 발견된 `OpenGL error INVALID_ENUM` 및 `render not being called` 경고 정리 → 창 크기 변경 시 미세 끊김 제거 | 로그로 원인 파악됨 |
| 오디오 장치 스마트 감지 | 재생 시작 전에 연결된 장치의 패스스루 지원 여부를 미리 확인하여, 실패-복구 과정 없이 처음부터 올바른 모드로 시작 (첫 소리까지의 시간 단축) | 설계 완료 |
| 오디오 장치 선택 UI | 설정에서 출력 장치를 직접 선택 (USB DAC / HDMI 리시버 / 스피커), 장치별 Exclusive·패스스루 자동 프로필 | 기획 |
| 화면 끊김 최종 점검 | video-sync 모드 자동 최적화 (디스플레이 주사율과 영상 fps에 따라) | 기획 |

### 2순위: HiFi 음악 플레이어 모드 완성 (v4.5.x)

| 기능 | 설명 |
| --- | --- |
| 앨범 아트 / 태그 표시 강화 | 내장 태그(ID3/FLAC) 앨범 아트 추출, 곡 정보 패널 |
| 가사 동기화 | 인터넷 가사 검색 + 시간 동기화 표시 |
| EQ 프리셋 | 음악 모드 전용 파라메트릭 EQ (Rock/Jazz/Classical/Flat 등) |
| 갭리스 재생 | 앨범 연속 재생 시 곡 간 무음 제거 |
| 비트퍼펙트 표시 | 현재 출력 경로(샘플레이트/비트뎁스/Exclusive 여부) 실시간 표시 |

### 3순위: OTT / 고급 기능 (v4.6.x 이후)

| 기능 | 설명 |
| --- | --- |
| OTT 모드 개선 | Edge WebView2 기반 넷플릭스/유튜브 뷰어 + Dolby Access 연동 안내 |
| 유튜브 5.1 서라운드 | yt-dlp 연동 E-AC3 스트림 자동 선택 (구현됨, 안정화 필요) |
| AI 실시간 자막 | 음성 인식 기반 실시간 자막 (Whisper 연동) |
| AI 업스케일링 | Anime4K/FSRCNNX 셰이더 기반 실시간 업스케일 옵션 |
| 스마트 챕터/북마크 | 챕터 썸네일, 구간 북마크 저장 |
| 재생 기록 | 최근 파일 목록, 이어보기 (마지막 위치 기억) |
