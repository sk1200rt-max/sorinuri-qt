# 소리누리 HiFi 음악 플레이어 UI/UX 상세 기획안

이 문서는 소리누리 v3.0에 새롭게 도입된 HiFi 음악 플레이어 모드의 상세 UI/UX 설계와 화면 구성을 정의합니다. 오디오파일(Audiophile)을 위한 전문적인 기능과 대기업 수준의 세련된 디자인을 결합하여, 사용자가 시각적 만족감과 음질적 신뢰감을 동시에 느낄 수 있도록 기획되었습니다.

## 1. 디자인 철학 및 원칙

소리누리 HiFi 모드의 디자인은 다음 세 가지 핵심 원칙을 바탕으로 설계되었습니다.

첫째, **플랫 디자인 기반의 명확성**입니다. 불필요한 네온 효과나 과도한 3D 효과를 배제하고, 솔리드 컬러와 미세한 그라데이션만을 사용하여 세련되고 현대적인 느낌을 줍니다. 배경은 `#0e0e0e` 수준의 다크 테마를 채택하여 장시간 사용 시 눈의 피로를 최소화합니다.

둘째, **텍스트와 정보의 시인성 확보**입니다. 오디오 코덱, 샘플레이트, 비트 심도 등 전문적인 오디오 정보는 고정폭(Monospace) 폰트와 명확한 테두리 배지를 사용하여 가독성을 높였습니다. 

셋째, **시각적 몰입감 제공**입니다. 현재 재생 중인 앨범 아트를 기반으로 전체 배경에 블러 처리를 적용하여(Spotify 스타일), 곡마다 플레이어의 전체적인 색조가 자연스럽게 변화하도록 설계했습니다.

## 2. 화면 구성 및 레이아웃

HiFi 모드는 크게 좌측의 플레이어 컨트롤 영역(38%)과 우측의 정보 영역(62%)으로 나뉘며, 우측 영역은 사용자의 선택에 따라 가사, 재생목록, 이퀄라이저 패널로 전환됩니다.

### 2.1 메인 플레이어 영역 (좌측 38%)

좌측 영역은 음악 감상의 핵심 정보와 조작부를 포함합니다.

| UI 요소 | 상세 사양 및 동작 |
| :--- | :--- |
| **앨범 아트** | 280x280 픽셀의 원형 마스크가 적용됩니다. 재생 중일 때는 1초에 1도씩 천천히 회전하며, 테두리에 은은한 청록색(Teal) 글로우 효과가 추가됩니다. |
| **트랙 정보** | 곡 제목은 22px 굵은 흰색 폰트로, 아티스트와 앨범명은 13~15px의 회색 폰트로 중앙 정렬되어 표시됩니다. |
| **오디오 배지** | `[FLAC]`, `[24bit]`, `[192kHz]`, `[Stereo]` 등 현재 트랙의 물리적 오디오 스펙을 나타냅니다. 특히 비트 퍼펙트 출력이 활성화된 경우 눈에 띄는 초록색 `[BIT-PERFECT]` 배지가 표시됩니다. |
| **오디오 스펙트럼** | 64개의 막대로 구성된 실시간 주파수 시각화 영역입니다. 저음역대(파랑)에서 고음역대(청록)로 이어지는 색상 그라데이션이 적용되며, 피크 홀드 점이 함께 렌더링됩니다. |
| **재생 컨트롤** | 셔플, 이전 곡, 재생/일시정지, 다음 곡, 반복 버튼이 배치됩니다. 재생 버튼은 48x48 픽셀의 원형 버튼으로 강조됩니다. |

### 2.2 동기화 가사 패널 (우측 62% - 기본 상태)

음악 파일에 포함된 LRC 메타데이터나 인터넷(LRCLIB API)에서 실시간으로 가져온 가사를 표시합니다.

*   **타이포그래피**: 현재 재생 중인 가사 줄은 18px 굵은 흰색으로 중앙에 크게 표시되며, 이전/이후 가사는 거리에 따라 투명도와 크기가 점진적으로 작아집니다(14px → 13px → 12px).
*   **시각 효과**: 패널 상하단에 어두운 그라데이션 마스크를 적용하여 가사가 부드럽게 나타나고 사라지도록 처리했습니다.
*   **소스 표시**: 우측 상단에 `[LRC] 동기화` 또는 `[LRCLIB] 동기화` 배지를 통해 가사의 출처를 명확히 안내합니다.

### 2.3 이퀄라이저(EQ) 패널 (우측 62% - 설정 시)

오디오파일을 위한 10밴드 파라메트릭 이퀄라이저 설정 화면입니다.

*   **프리셋 선택기**: 가로 스크롤이 가능한 버튼 행으로, `Flat`, `Audiophile`, `Bass Boost`, `Vocal`, `Classical`, `Rock`, `Jazz` 7가지 내장 프리셋을 제공합니다. 선택된 프리셋은 청록색으로 강조됩니다.
*   **10밴드 슬라이더**: 31Hz부터 16kHz까지 10개의 주파수 대역을 조절합니다. 각 슬라이더 상단에는 현재 설정된 게인 값(예: `+1.5dB`, `-0.5dB`)이 실시간으로 표시됩니다.
*   **주파수 응답 곡선**: 슬라이더 하단에 설정된 EQ 값을 기반으로 부드러운 스플라인 곡선을 그려, 전체적인 주파수 응답 특성을 시각적으로 보여줍니다.

### 2.4 재생목록 패널 (우측 62% - 목록 뷰)

여러 곡을 재생할 때 표시되는 트랙 관리 화면입니다.

*   **트랙 리스트**: 각 행은 트랙 번호, 소형 앨범 아트(36x36), 제목, 아티스트, 재생 시간, 오디오 포맷 배지로 구성됩니다.
*   **현재 재생 트랙**: 리스트에서 현재 재생 중인 곡은 배경색이 미세하게 밝아지고, 좌측에 청록색 하이라이트 바가 표시되어 쉽게 식별할 수 있습니다.
*   **조작 편의성**: 드래그 앤 드롭을 통한 순서 변경 기능을 지원하며, 상단 검색창을 통해 수백 곡의 목록에서도 원하는 곡을 즉시 찾을 수 있습니다.

## 3. 미니 플레이어 모드

작업 중 배경 음악을 감상하는 사용자를 위한 콤팩트 모드입니다.

*   **크기 및 위치**: 400x80 픽셀의 작은 크기로, 화면 우측 하단에 항상 위(Always on Top) 상태로 플로팅됩니다.
*   **구성 요소**: 좌측에 48x48 소형 앨범 아트가 배치되고, 중앙에 곡 정보와 시크바가 겹쳐서 표시됩니다. 우측에는 간소화된 재생 컨트롤과 오디오 배지가 위치합니다.
*   **시인성**: 반투명한 `#0a0a0a` 배경을 사용하여 바탕화면과 자연스럽게 어우러지면서도 컨트롤 요소는 명확하게 보이도록 설계했습니다.

## 4. 모드 자동 전환 시나리오

소리누리는 파일의 특성을 분석하여 최적의 모드로 자동 전환합니다.

1.  사용자가 미디어 파일을 드래그 앤 드롭하거나 열기 대화상자를 통해 선택합니다.
2.  엔진이 파일의 확장자(FLAC, WAV, MP3, DSD 등)를 확인합니다.
3.  음악 파일로 판별될 경우, 영상 렌더러를 숨기고 즉시 HiFi MusicWidget을 화면에 표시합니다.
4.  MPV 엔진의 오디오 설정을 비트 퍼펙트 모드(샘플레이트 변환 금지, float 처리)로 재구성합니다.
5.  파일 내장 태그와 폴더 내 커버 이미지를 스캔하여 UI에 반영하고 재생을 시작합니다.

이러한 끊김 없는 전환을 통해 사용자는 별도의 설정 없이도 동영상과 고음질 음악 감상을 하나의 플레이어에서 완벽하게 경험할 수 있습니다.
