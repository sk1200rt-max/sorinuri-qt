# 소리누리 HiFi 음악 플레이어 모드 기획안

**버전**: v3.0 예정  
**작성일**: 2026-07-29

---

## 1. 핵심 철학

> "이 플레이어를 쓰면 확실히 음질이 달라."

EQ로 음색을 바꾸는 것이 아니라, **원본 신호를 손실 없이 최대한 정확하게 재생**하는 것이 목표다. 소리누리 HiFi 모드는 다음 세 가지 원칙을 따른다.

1. **비트 퍼펙트(Bit-Perfect)**: 원본 파일의 비트를 단 하나도 변형하지 않고 DAC에 전달
2. **배타적 출력(Exclusive Mode)**: Windows 오디오 믹서를 완전히 우회하여 다른 앱의 간섭 차단
3. **정확한 클럭(Accurate Clocking)**: 샘플레이트 변환 없이 원본 샘플레이트 그대로 출력

---

## 2. 자동 모드 전환

음악 파일(FLAC, WAV, AIFF, DSD, MP3, AAC, ALAC 등)을 열면 **자동으로 HiFi 음악 플레이어 모드로 전환**된다. 영상 파일을 열면 다시 영상 플레이어 모드로 돌아온다.

```
파일 열기
    │
    ├─ 영상 파일 (MKV, MP4, AVI...) → 영상 플레이어 모드
    │
    └─ 음악 파일 (FLAC, WAV, MP3...) → HiFi 음악 플레이어 모드
            │
            ├─ UI: 앨범 아트 + 트랙 정보 + 스펙트럼
            ├─ 오디오: WASAPI Exclusive + 비트 퍼펙트
            └─ 가사: 인터넷 자동 검색 + 동기화
```

## 3. HiFi 음질 기술 스택

### 3.1 WASAPI Exclusive Mode (현재 적용 중)

Windows Audio Session API의 배타적 모드. 소리누리가 오디오 장치를 독점하여 Windows 믹서(KMixer)를 완전히 우회한다.

- **효과**: 리샘플링 없음, 비트 변형 없음, 다른 앱 오디오 차단
- **현재 상태**: 이미 구현됨

### 3.2 비트 퍼펙트 출력 (추가 구현)

| 파일 포맷 | 비트 깊이 | 샘플레이트 | 출력 방식 |
|:---|:---:|:---:|:---|
| FLAC 24bit/192kHz | 24bit | 192kHz | WASAPI Exclusive 192kHz 그대로 |
| WAV 32bit/384kHz | 32bit | 384kHz | WASAPI Exclusive 384kHz 그대로 |
| DSD64/DSD128 | 1bit | 2.8/5.6MHz | DoP(DSD over PCM) 또는 네이티브 DSD |
| ALAC 24bit/96kHz | 24bit | 96kHz | WASAPI Exclusive 96kHz 그대로 |
| MP3 320kbps | 16bit | 44.1kHz | WASAPI Exclusive 44.1kHz |

MPV의 `audio-samplerate=0` (원본 유지), `audio-format=float` (32bit float 내부 처리) 설정으로 구현.

### 3.3 ReplayGain 지원

앨범/트랙 간 볼륨 차이를 자동으로 보정한다. FLAC/MP3 태그에 포함된 ReplayGain 값을 읽어 적용.

- `replaygain=album`: 앨범 단위 볼륨 정규화
- `replaygain=track`: 트랙 단위 볼륨 정규화
- `replaygain=no`: 원본 볼륨 그대로 (비트 퍼펙트)

### 3.4 업샘플링 옵션 (선택적)

비트 퍼펙트가 기본이지만, DAC 성능을 최대한 활용하고 싶은 사용자를 위한 고품질 업샘플링 옵션을 제공한다.

| 알고리즘 | 품질 | CPU 부하 | 설명 |
|:---|:---:|:---:|:---|
| **없음 (기본)** | 원본 | 없음 | 비트 퍼펙트, 가장 순수 |
| SoX Very High | ★★★★★ | 중간 | 최고 품질 업샘플링 |
| SoX High | ★★★★ | 낮음 | 균형 잡힌 품질 |
| Linear | ★★ | 매우 낮음 | 단순 선형 보간 |

MPV의 `audio-resample-filter-size`, `audio-resample-phase-shift` 파라미터로 제어.

### 3.5 EQ 프리셋 (선택적, 비트 퍼펙트 모드에서는 비활성)

| 프리셋 | 설명 |
|:---|:---|
| Flat (기본) | EQ 없음, 원본 그대로 |
| Audiophile | 고역 약간 강조, 공간감 확장 |
| Bass Boost | 저음 +3dB |
| Vocal | 중역 강조, 보컬 선명도 향상 |
| Classical | 넓은 다이나믹 레인지, 자연스러운 공간감 |
| Rock | 저음/고음 강조, 중역 약간 감소 |
| Jazz | 따뜻한 중역, 부드러운 고역 |
| 사용자 정의 | 10밴드 파라메트릭 EQ 직접 조정 |

### 4.2 앨범 아트

- FLAC/MP3/ALAC 파일 내 임베디드 커버 아트 자동 추출
- 없으면 폴더 내 `cover.jpg`, `folder.jpg`, `albumart.jpg` 순서로 탐색
- 없으면 음악 장르별 기본 이미지 표시
- 앨범 아트를 배경으로 블러 처리하여 전체 배경에 적용 (Spotify 스타일)

### 4.3 파일 정보 태그

ID3v2 / Vorbis Comment / APEv2 태그에서 자동 추출:

| 태그 | 표시 위치 |
|:---|:---|
| 제목 (Title) | 트랙 제목 (크게) |
| 아티스트 (Artist) | 아티스트명 |
| 앨범 (Album) | 앨범명 |
| 연도 (Year) | 앨범명 옆 작게 |
| 장르 (Genre) | 하단 정보 |
| 트랙 번호 | 재생목록에서 표시 |
| 비트 깊이 / 샘플레이트 | 오디오 정보 태그 영역 |
| ReplayGain 값 | 설정 패널에서 표시 |

## 5. 가사 동기화 기능

### 5.1 가사 소스 우선순위

```
1순위: 파일 내 임베디드 가사 (ID3 USLT 태그, FLAC LYRICS 태그)
2순위: 같은 폴더의 .lrc 파일 (타임스탬프 동기화 가사)
3순위: 인터넷 자동 검색
    ├─ Musixmatch API (가장 정확, 동기화 지원)
    ├─ NetEase Cloud Music API (한국/중국 음악 강점)
    └─ LRCLIB (오픈소스, 무료)
```

### 5.2 .lrc 형식 지원

```
[00:12.34] 첫 번째 가사 줄
[00:16.78] 두 번째 가사 줄
[00:21.00] 세 번째 가사 줄
```

타임스탬프 기반으로 현재 재생 위치에 맞는 줄을 강조 표시한다.

### 5.3 가사 표시 UI

- 현재 줄: 흰색, 16px, 중앙 정렬
- 이전/다음 줄: 회색 50% 투명도, 13px
- 스크롤: 현재 줄이 항상 중앙에 위치하도록 부드럽게 스크롤
- 가사 없을 때: "가사를 찾을 수 없습니다" + 수동 입력 버튼

## 6. 스펙트럼 시각화 (음악 모드 전용)

영상 플레이어에서는 스펙트럼이 의미 없지만, **음악 파일 재생 시에는 완전히 다른 맥락**이다.

- 소프트웨어 디코딩이므로 PCM 데이터에 항상 접근 가능
- 앨범 아트 오른쪽에 실시간 주파수 막대 표시
- 원형 모드: 앨범 아트를 중심으로 원형 스펙트럼 (음악 감상 몰입감)
- 파형 모드: 좌/우 채널 파형을 분리 표시
